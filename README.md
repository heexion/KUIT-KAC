# 🍽️ 냠코치

> 식단과 운동을 기록하고 개인화된 피드백을 제공하는 다이어트 코칭 애플리케이션

냠코치는 사용자가 매일의 식단과 운동을 기록하고 목표에 따른 섭취 현황과 피드백을 확인할 수 있는 Native Android App입니다.

단순히 칼로리를 기록하는 것에서 그치지 않고 사용자의 목표와 현재 상태를 비교하여 지속적인 식단 관리를 돕는 것을 목표로 개발했습니다.

---

## 💡 Background

식단 관리 서비스는 섭취한 음식을 기록할 수 있지만 입력된 정보를 사용자가 어떻게 활용해야 하는지 충분히 설명하지 못하는 경우가 많습니다.

냠코치는 식단 기록을 목표 칼로리와 영양소 정보에 연결하고 사용자의 현재 상태를 직관적으로 보여줌으로써 스스로 식습관을 관리할 수 있도록 기획한 서비스입니다.

## 🔍 Technical Highlights

### 사용자 데이터에 따른 영양 정보 처리

사용자의 목표 칼로리와 실제 섭취량을 비교하여 현재 상태를 화면에 반영했습니다.

칼로리가 0인 경우, 목표치를 초과한 경우, 영양 정보가 없는 경우에도 화면 요소가 겹치거나 앱이 종료되지 않도록 상태별 예외 처리를 적용했습니다.

### 로그인과 온보딩 데이터 연동

소셜 로그인 이후 사용자 정보를 입력하고 서버에 전달하는 온보딩 흐름을 연결했습니다.

로그인, 권한 요청, 사용자 정보 입력 과정이 순차적으로 진행될 수 있도록 화면 이동과 데이터 전달 구조를 구성했습니다.

### 불완전한 데이터에 대한 예외 처리

식단, 운동 루틴 등 서버에서 전달되는 데이터가 비어 있는 경우에도 앱이 종료되지 않도록 방어 로직을 적용했습니다.

목표 칼로리, 잔여 칼로리, 영양소 값에 따라 텍스트와 그래프가 비정상적으로 표시되는 문제도 함께 개선했습니다.
